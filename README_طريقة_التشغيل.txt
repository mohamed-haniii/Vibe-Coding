================================================================
          دليل التشغيل السحابي - برنامج عيادة التخسيس والتغذية
                  (Google Firebase Cloud Edition)
================================================================

أهلاً بك! تم تحويل وتجهيز المشروع بالكامل ليعمل بالسيرفر السحابي (Google Firebase):

مميزات النظام السحابي الجديد:
----------------------------------------------------------------
1. لا تحتاج لضبط أي عناوين IP أو شبكات محلية بعد الآن.
2. لا يحدث أي تعارض بين الأجهزة أو قواعد بيانات منفصلة.
3. المزامنة فورية وتلقائية بين شاشة الدكتورة وشاشة الاستقبال عبر الإنترنت.
4. يمكنك فتح البرنامج من أي جهاز (كمبيوتر الدكتورة، كمبيوتر الاستقبال، لابتوب من المنزل، أو موبايل) بنقرة واحدة عبر الرابط المباشر.

طريقة الاستخدام السريعة:
----------------------------------------------------------------
1. افتح رابط النظام في متصفح Chrome أو Edge على جهاز الدكتورة وجهاز الاستقبال.
2. في شاشة الدخول:
   - جهاز الدكتورة: اختر "👩‍⚕️ حساب الدكتورة" (اسم المستخدم: admin / كلمة المرور: admin123).
   - جهاز الاستقبال: اختر "🖥️ حساب الاستقبال" (اسم المستخدم: cashier1 / كلمة المرور: cashier123).
3. سيعمل الجهازان معاً بشكل متزامن في اللحظة والثانية (Real-time).

لتشغيل السيرفر المحلي في حال رغبتك:
----------------------------------------------------------------
- اضغط مرتين على ملف ( تشغيل_البرنامج_نقرة_واحدة.bat ) أو ( run.bat ) وسيبدأ السيرفر ويفتح المتصفح تلقائياً.
